✨ Key Features

🔵🟢
Blue-Green Deployments
Zero-downtime deploys by running two environments and switching traffic only after health checks pass. Instant rollback if anything fails.
🏗️
Multi-Stage Docker Builds
Build stage compiles the app; production stage copies only what's needed — no dev dependencies, non-root user, minimal attack surface.
🔐
SSL Automation
Let's Encrypt certificates obtained and renewed automatically via Certbot. Auto-renewal cron job included. Nginx hot-reloads on renewal.
📊
Full Monitoring Stack
Uptime monitor script polls all services every 30s. Prometheus + alert rules for metrics. Slack/email alerts with cooldown to avoid noise.
🌍
Environment Configs
Separate .env files for dev, staging, and production. Docker Compose variants for each environment. pgAdmin and Redis Commander in dev profile.
🛡️
Security Hardened
Nginx rate limiting, CSP headers, HSTS. UFW firewall + fail2ban on server. JWT auth with refresh tokens. SSH password auth disabled.

📐 Architecture

# Traffic Flow
User (HTTPS) → UFW Firewall → Nginx (SSL termination + rate limiting)
                                           ↓
                                   Backend (Blue or Green) :5000/:5001
                                           ↓           ↓
                             PostgreSQL :5432    Redis :6379

# CI/CD Flow (GitHub Actions)
git push → lint → test (docker-compose.test.yml) → docker build
          → push to GHCR → ssh to VPS → deploy.sh (blue-green)
          → health check → [pass] done | [fail] rollback.sh
